## Why a laptop?

Using a laptop as a server has some advantages:

- low power consumption
- built-in battery
- built-in display
- built-in keyboard
- relatively small size
- already available hardware

It also introduces some challenges:

- cooling
- battery health
- power management
- limited storage expansion
- hardware designed for mobile use rather than continuous server operation


## Future hardware improvements

Possible improvements include:

- larger storage
- dedicated server hardware
- better cooling
- external backup storage
- UPS/power protection
- improved networking
